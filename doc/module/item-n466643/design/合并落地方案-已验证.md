## 3. 步骤三：2 个手工合并文件

做法是**以源版为基底，再把目标侧独有的三处补回去**——而不是在目标版上手工加源侧的
新逻辑。理由：源侧改动分散在 struct 字段、构造函数、`Start()`、`checkDeviation()`、
开仓分支五处且互相牵连；目标侧独有的只有 `stopOnce` 与 `Config()` 两个正交点，补回去
比拆开源侧改动风险低得多。

```bash
cp "$S/pkg/monitor/price_monitor.go" "$T/pkg/monitor/price_monitor.go"
cp "$S/pkg/trade/manager.go"        "$T/pkg/trade/manager.go"
```

然后执行下面这段补丁（已实测通过，三处 `assert` 是防止源文件变动后静默改错）：

```python
import re, pathlib
T = pathlib.Path("server/argus_single")

# ---- price_monitor.go：补回 stopOnce ----
pm = T/"pkg/monitor/price_monitor.go"
s = pm.read_text()
s = s.replace('badelay500w/common/', 'common/')
s = s.replace('\tstopChan           chan struct{}              // 停止信号\n',
              '\tstopChan           chan struct{}              // 停止信号\n'
              '\tstopOnce           sync.Once\n', 1)
old = '''	close(pm.stopChan)
	pm.wg.Wait()
	logrus.Info("价格监控已停止")'''
new = '''	pm.stopOnce.Do(func() {
		close(pm.stopChan)
		pm.wg.Wait()
		logrus.Info("价格监控已停止")
	})'''
assert s.count(old) == 1
pm.write_text(s.replace(old, new, 1))

# ---- manager.go：补回 stopOnce + Config() ----
mg = T/"pkg/trade/manager.go"
s = mg.read_text()
s = s.replace('badelay500w/common/', 'common/')
assert '\ttrendGateThresholdByAccount   map[string]float64' in s
s = s.replace('\ttrendGateThresholdByAccount   map[string]float64',
              '\tstopOnce                      sync.Once\n'
              '\ttrendGateThresholdByAccount   map[string]float64', 1)
cfg = '''
func (tm *TradeManager) Config() *TradingSystemConfig {
	tm.mu.RLock()
	defer tm.mu.RUnlock()
	if tm.config == nil {
		return nil
	}
	copy := *tm.config
	copy.Accounts = append([]AccountConfig(nil), tm.config.Accounts...)
	return &copy
}
'''
m = re.search(r'\nfunc NewTradeManager\(', s)
assert m
s = s[:m.start()] + '\n' + cfg + s[m.start():]
old = '''	close(tm.stopShuffle)
	if tm.loginScheduler != nil {
		tm.loginScheduler.Stop()
	}
	logrus.Info("🛑 TradeManager已停止")'''
new = '''	tm.stopOnce.Do(func() {
		close(tm.stopShuffle)
		if tm.loginScheduler != nil {
			tm.loginScheduler.Stop()
		}
		logrus.Info("🛑 TradeManager已停止")
	})'''
assert s.count(old) == 1
mg.write_text(s.replace(old, new, 1))
```

**为什么 `stopOnce` 不能省**：`runtimeconfig.ReloadMonitor` / `ReplaceManager` 会对旧实例
调 `Stop()`，热替换路径上同一实例可能被停两次，没有 `stopOnce` 就是 `close of closed
channel` panic。这是目标侧独有改造的正确性前提（主文档 §4.2、V7）。

**为什么 `Config()` 不能省**：`pkg/runtimeconfig/runtime.go` 靠它读当前配置做快照对比，
删掉直接编译失败。
