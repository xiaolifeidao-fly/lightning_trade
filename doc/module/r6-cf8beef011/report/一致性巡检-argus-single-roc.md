## 6. 口径备注

- 回灌行 `source=2`、`config_version=0`：历史事件没有可考的配置版本，留 0 与直写的真实版本号区分开。
- `uid` 由该实例 properties 的 `trade.accountN.name/uid` 映射而来；事件里从来没有 uid，未知标签一律拒绝导入而不猜。
- `instrument` 归一化到 `BTCUSDT`，`inst_id_raw` 保留 JSONL 原值（信号侧 `BTCUSDT` / 持仓侧 `BTC-USDT-SWAP` 100% 分裂）。
- `net_size_known` 按「天 × 账户」自适应判定：当天该账户出现过带 `size` 的 balance ⇒ 同日缺失即已知空仓；一条都没有 ⇒ 全天未知。
- 历史 JSONL 只读，本工具不修改、不移动、不删除任何原文件。
